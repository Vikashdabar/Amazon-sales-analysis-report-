# 📊 Amazon Sales Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Amazon Sales Analytics Dashboard** built using **Microsoft Power BI**. The goal of this project is to analyze Amazon product data and identify patterns and trends across product categories, pricing, discounts, customer ratings, and review counts.

The dashboard transforms a large and relatively raw Amazon product dataset into an interactive business intelligence report that allows users to explore product and category performance through visualizations and filters.

The project includes both an **Executive Summary** and a **Category Analysis** page, with a focus on presenting complex product data in a simple and decision-friendly format.

---

## 🎯 Business Objectives

The dashboard was designed to answer questions such as:

- Which product categories offer the highest discounts?
- Which categories have the highest average ratings?
- Which categories contain the largest number of products?
- Which products have the highest discounted prices?
- Which products have the highest number of customer reviews?
- Is there a relationship between product price and customer rating?
- How does product pricing vary across different categories?

---

## 📊 Dashboard Pages

### 1. Executive Summary

The Executive Summary provides a high-level overview of the dataset using:

- Total number of products
- Average discounted price
- Average actual price
- Average customer rating
- Discount analysis by category
- Products with the highest discounted prices
- Top products based on rating/review count
- Interactive rating filters

### 2. Category Analysis

The Category Analysis page provides a more detailed exploration of:

- Average discount by category
- Average customer rating
- Product count by category
- Price vs. rating relationship
- Category-level product analysis
- Interactive filtering

## 🔄 Data Analysis Process

The project follows a typical data analyst workflow:

**Raw Data → Data Cleaning → Transformation → Data Modeling → DAX Measures → Visualization → Insights**

### Data Preparation

The original dataset contains a large number of products with detailed and hierarchical category names. Instead of manually changing the raw values, the original data was preserved and transformations were performed using Power Query where required for analysis and visualization.

The data preparation process included:

- Handling raw product and category data
- Transforming category fields
- Preparing numerical fields for analysis
- Creating calculated measures using DAX
- Preparing data for interactive visualizations
